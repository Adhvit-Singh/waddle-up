# Round 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Natural craggy mountain + rocky ledges + scenery, 3× traps with 8 new types and no-repeat rules, the bouncy ledge fix, and a local-only developer menu.

**Architecture:** The pure generators (`MountainData`) gain a path-corridor model, which the rock noise must respect; tests prove ledges are unchanged and nothing blocks or traps the player. The trap logic stays in the testable `TrapDirector`, with new behaviours as small modules. The dev menu sits entirely behind `import.meta.env.DEV`.

**Tech Stack:** Same as before (three, Rapier, TS, Vite, node:test). Headless Edge driver (`e2e/cdp.mjs`, moved into the repo) for play checks.

**Spec:** `docs/superpowers/specs/2026-11-17-round2-mountain-traps-design.md`

## Global Constraints
- Ledge specs (index, kind, stage, pos, size, rot) stay byte-for-byte identical. The main RNG call order in `generateMountain` must not change, and all new randomness uses separate seeds.
- Collision boxes of ledges are unchanged.
- No new npm packages.
- The Unity project is read-only.
- Update `GAME_LOG.md` at the end.

## Review Focus
1. **Penguin wedged between a spur and a ledge underside:** the corridor clamp must cover from 2 m below the ledge underside to 3.5 m above its top (test: `mountain.test.ts › corridor clear`).
2. **Fake-summit rise with pines/rock** → pines move with the tier root and the plateau stays walkable (e2e summit flow).
3. **Trap during a cutscene/pause** → no new trap fires and timers don't run (existing `isPlaying` guard; e2e force-fire while paused does nothing).
4. **Input-delay and camera-troll traps overlapping a pause or a send-to-bottom** → effects end cleanly after `resetWorld` (test: `traps.test.ts › effects reset`).
5. **Dev code leaking into the deploy** → `tests/dist.test.ts` scans `dist/assets/*.js` for `DEV MENU`.
